LINE-IN / MIC REACTIVESoundclash Visualizer

Looping video clips with a live graph on top: LED bars that light up on kicks, snares and hats, plus an optional MilkDrop layer, all driven by whatever your sound card hears. Plug the DJ feed into line-in (or just let the mic hear the room), pick that input, and go fullscreen.

Open this file in Chrome or Edge. The browser asks for microphone permission once per launch; nothing is recorded or sent anywhere, and everything runs offline.

SHOW MODE

The show moves through every border by itself, each one turning smoothly into the next, and brings the graph in and out. While it runs it sets the border, the graph and the video zoom. Everything else stays as you set it.

VIDEO CLIPS

    BORDER

    Everything outside the picture is pure black, so a projector shows only the shape, not its own rectangle. The blob grows into the border on each kick, so give the border some width. The border covers the edges of the picture so clips with different built-in borders look the same. Set each pair just wide enough to hide them. Video zoom enlarges the picture instead, so a clip's own border falls off the screen; it works with the border off too. The graph and status text move inside the border.

    JAPANESE TEXT

    Each kick drops a few labels at random spots inside the picture. They flash white, then fade. Note names are read from the music and sit left to right by pitch.
