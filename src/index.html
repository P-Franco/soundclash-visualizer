LINE-IN / MIC REACTIVESoundclash Visualizer

Looping video clips with a live graph on top: LED bars that light up on kicks, snares and hats, plus an optional MilkDrop layer, all driven by whatever your sound card hears. Plug the DJ feed into line-in (or just let the mic hear the room), pick that input, and go fullscreen.

Open this file in Chrome or Edge. The browser asks for microphone permission once per launch; nothing is recorded or sent anywhere, and everything runs offline.

    BEAT CUTS

    Counts hits in the KICK zone. Beat cuts are always hard cuts, whatever the crossfade is set to. With one clip in the list, a cut jumps to a random point in it.

    BORDER

    The border covers the edges of the picture so clips with different built-in borders look the same. Set each pair just wide enough to hide them. Video zoom enlarges the picture instead, so a clip's own border falls off the screen; it works with the border off too. The graph and status text move inside the border.
